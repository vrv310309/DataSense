# DataSense

**An AI-powered data analyst that turns CSV and Excel files into visualizations, patterns and actionable insights.**

DataSense is a beginner-friendly data exploration app built with Python and Streamlit. The current MVP focuses on transparent, reproducible statistical analysis. It does **not** yet connect to a generative AI/LLM service; that is a planned extension.

## Features

- Upload CSV and Excel (`.xlsx`, `.xls`) datasets
- Dataset profile: row/column counts, data types, unique values and missing values
- Descriptive statistics for numeric columns
- Data-quality checks for missing cells and duplicate rows
- Potential numeric outlier screening using the IQR method
- Interactive histogram, category bar chart, scatter plot and correlation heatmap
- Search and preview data
- Export filtered data as CSV and analysis as Markdown

## Run locally

Python 3.10 or newer is recommended.

```bash
# 1. Clone the repository
git clone https://github.com/vrv310309/DataSense.git
cd DataSense

# 2. Create and activate a virtual environment
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the app
streamlit run app.py
```

Open the local URL printed by Streamlit (usually http://localhost:8501).

## Privacy and data handling

The app reads the uploaded file into the active Streamlit server session for analysis. This code does not intentionally write uploaded datasets into the repository or send them to an external AI provider. If you deploy the app, the hosting provider's infrastructure, logging, retention, and access policies also apply. Do not upload confidential or sensitive data to a deployment unless you have reviewed those policies.

## Current limitations

- Insights are statistical/rule-based, not generated by an LLM.
- Outlier flags are indicative and require human review.
- Large datasets may need performance optimization.
- Excel files with unusual formatting or multiple complex sheets may need preprocessing.
